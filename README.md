# entities-multiplayer-fabric-interaction-system-project

An engine test project for the fabric interaction system add-on, driven by a mouse on the desktop or by controllers in XR.

## What it is for

It enables three add-ons, the interaction system, the 3D canvas and the shader debug drawing add-on (`addons/s2h`), in one scene, so laser, lasso and canvas interaction can be tried with either input.

## Run it

Open `project.godot` in a double-precision engine editor and run the main scene.
